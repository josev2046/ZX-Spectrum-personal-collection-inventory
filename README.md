# Sinclair ZX Spectrum personal collection inventory

Inventory and technical assessment of seven Sinclair ZX Spectrum microcomputers and associated peripherals currently kicking around my lab (Feb 2026). This collection comprises seven distinct units ranging from early 1983 manufacture (Issue 2) to late 1984 production. It includes one factory-original "Series 1" 16K model, one verified "hybrid" unit (Issue 2 board in later case), and several Dundee-manufactured Issue 3 models. Condition ranges from "Museum Grade" restored examples to "For Parts" donor units. Valuations and technical notes are derived from serial number analysis, internal motherboard inspection, and functional testing. Work in progress...
